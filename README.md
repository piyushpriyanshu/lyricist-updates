# Lyricist updates

Release files for the Lyricist Android app (Hindi lyrics). The app reads `update.json` and installs newer versions by itself.

- **Latest:** 3.2.0 ([download APK](apk/Lyricist-3.2.0.apk))
- **Manual install:** open the APK on your phone and allow installs from your browser or file manager.

What's new in 3.2.0:

- Floating lyrics show only while a song is playing (no more overlay after the phone starts)
- Long lyric lines are shown in full in the floating lyrics, never cut off with …
- Songs from YouTube-based music apps are recognised by their real title
- Trending refreshes properly and adds Apple Music's daily chart
- Automatic updates from GitHub
